## Design Principles

1. **Professional CAD Feel** - Familiar workflows for engineers and designers
2. **Scalable UI** - Responsive layout that works at different DPI scales
3. **Keyboard-First** - Efficient keyboard shortcuts for power users
4. **Context-Aware** - UI adapts to current editing mode (sketch vs solid)
5. **Visual Clarity** - Clear visual hierarchy and feedback
